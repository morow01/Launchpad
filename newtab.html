Sync between PCs

Keep your shortcuts, settings and background the same on every PC, through private Gists in your GitHub account.

  1. Create a GitHub token — only the gist box ticked. Choose an expiry (or “No expiration”), then click Generate token.
  2. Copy the token and paste it here:

Then do the same on your other PC — it finds the same data. The token stays on each PC and is never included in backups.

View on GitHub

Export & import

Export saves your shortcuts, settings and background to a file you can keep anywhere. Import loads such a file back. Sync already keeps your PCs safe and in step — this is for keeping your own copy.

About & other PCs

Launchpad

Install on another PC — paste into PowerShell:

  1. → turn on Developer mode → Load unpacked → pick the Launchpad folder in your user folder.
  2. Open a new tab → Settings → Sync between PCs → paste your token → Connect.

No Git on that PC? Download the ZIP and extract it to a folder you'll keep.
