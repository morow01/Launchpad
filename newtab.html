Sync between PCs

Keep your shortcuts, settings and background the same on every PC, through private Gists in your GitHub account.

  1. Create a GitHub token — only the gist box ticked. Choose an expiry (or “No expiration”), then click Generate token.
  2. Copy the token and paste it here:

Then do the same on your other PC — it finds the same data. The token stays on each PC.

  1. Paste it into PowerShell on the new PC.

  3. Open a new tab → Settings → Sync and data → paste your token → Connect.
